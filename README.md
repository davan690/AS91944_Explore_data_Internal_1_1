# AS91944_Explore_data_Internal_1_1

A Quarto website for notes, resources, interactive plots, and R-based analysis to support a statistical inquiry internal.

## Pages

- `index.qmd` introduces the site
- `resources.qmd` collects useful inquiry resources
- `interactive-plots.qmd` provides a live scatter plot example
- `analysis.qmd` shows a simple R analysis workflow

## Local preview

If Quarto and R are installed locally, preview the site with:

```bash
quarto preview
```
